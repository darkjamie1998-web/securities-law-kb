# 证券法律法规知识库 — 技术亮点

> 一个从公开官方来源采集、面向 AI Agent 的证券法律法规知识库：RAG 法条检索 + LLM 关联图谱 + 带引用溯源的对话研究。
> 本文面向技术评审与协作方，说明项目在架构与工程上的关键决策。数据规模：**879 部法规 / 5 万+ 法条 / 5062 条关系边**，全部沉淀在单个 89MB SQLite 文件中。

## 1. 全离线自包含便携分发（零安装、零网络、任意 Agent 接手）

分发包内嵌完整 Python 3.14.5 运行时（`runtime/`，含全部依赖）与知识库数据库，目标机器**无需安装 Python、无需联网装依赖**，解压双击即用。环境采用三级兜底：

```text
runtime\python.exe（便携形态） → .venv\Scripts\python.exe（开发形态）
  → 都没有？环境自检.bat 自动探测系统 Python（py -3 / python / python3）
    → tools/setup_env.py 在【项目文件夹内】自动创建 .venv 并装依赖（镜像源回退）
      —— 全程不修改系统 PATH / 注册表 / 全局站点
```

- 便携运行时 = 复制完整 Python 安装目录 + 合并已验证的 site-packages（`.venv` 因 `pyvenv.cfg` 硬编码绝对路径不可移植，弃用）
- `python.exe` 按自身位置定位 DLL 与标准库，路径无关，含中文的目录名下实测可用
- 未配置 LLM 时**关键词检索、法规浏览、图谱、测试、审计全部可用**；配置后解锁语义检索与 LLM 问答

## 2. 混合检索 RAG：中文 FTS5 + 向量 RRF 融合，可优雅降级

- **关键词路**：SQLite FTS5 trigram 分词（中文友好，≥3 字走 FTS，短词自动 LIKE 兜底），零外部依赖
- **向量路**：OpenAI 兼容 embeddings API（无本地嵌入模型，包体不膨胀）
- 两路结果 **RRF（Reciprocal Rank Fusion）融合**排序
- **降级设计**：当前网关不支持 embeddings 接口时向量路自动跳过，检索退化为纯关键词仍然可用——网关能力差异不阻断核心功能

## 3. LLM 关联知识图谱 + 完整性审计

- LLM 批量抽取法条间关系（引用/修改/衔接/同一事项等类型），构建 5062 条边的法规关联网络
- 前端 Canvas **径向分层图谱**（全景 + 16 个业务板块子图，零依赖无 d3/ECharts）
- wiki 解读按需生成 + 缓存复用，不重复烧 LLM
- `python -m app.audit` 图谱完整性审计：对称冗余边 / 孤立节点 / 幽灵标记三类检测，`--fix` 可修复历史丢边痕迹——图谱质量问题可度量、可自愈

## 4. 生产级可靠性工程（每一条都来自真实事故）

| 机制 | 防什么 | 怎么防 |
|------|--------|--------|
| **LLM 硬超时线程池兜底**（`app/llm.py`） | 网关"连接活着但不回响应"，httpx 库级超时失效（曾致图谱进程挂死 22 小时） | chat/embed 全走线程池 + `fut.result(hard_timeout)` 强制兜底 |
| **实例文件锁 + 看门狗**（`run_relations_forever.py`） | 双实例重复烧 LLM；进程挂死无人管 | msvcrt 文件锁（进程死亡自动释放）+ 45 分钟无产出自杀 + 失败重试上限 |
| **抽取标记表**（`relation_extractions`） | "天然无关系"的法规被无限重试 | pending 判定看标记而非产出——抽一次即完成，无论有没有关系 |
| **原子配置写入**（`app/config.py`） | 写盘途中崩溃留下半个 JSON | 临时文件 + `os.replace` 原子替换；文件损坏时回退默认配置而非 500 |
| **法条级联清理** | 法规内容更新后旧关系/解读残留 | sync 更新法规时显式删除其 relations/标记/wiki（FK 无 CASCADE） |

## 5. 合规反爬设计（对官方站点保持敬畏）

所有抓取统一走 `crawler/fetcher.py` 限频客户端：**每站串行、默认 ≥5s 间隔 + 随机抖动、指数退避重试、robots.txt 检查、单来源单日上限（默认 500）、连续失败熔断**。增量同步每日最多 1 次。仅采集公开发布的法律法规文本，来源清单（`crawler/sources.yaml`）逐项确认官方性质。

另含 **Playwright 无头浏览器渲染**（攻克 JS 动态列表页，仅列表页走浏览器、详情仍走 httpx 提速）与多格式解析：PDF（pdfplumber）、Word .docx（python-docx）、Word 97-2003 .doc（olefile UTF-16 扫描自研解析）。

## 6. 金融内网前端兼容（旧浏览器不是二等公民）

- **零框架零 CDN**：原生 HTML/CSS/JS 单页，无任何外部资源依赖，完全离线可用
- **ES2017 语法底线**：目标环境含 Chromium <80 旧浏览器，`??`/`?.` 等 ES2020 语法是**文件级**致命错误（一处不支持整个 app.js 交互失效）——代码规范强制约束
- **XSS 双防线**：渲染函数内置 `esc()`（防双重转义），外链一律过 `safeUrl()` 白名单
- CSS 新函数先写旧值回退再写新值

## 7. Windows 中文环境工程化（踩坑沉淀的可复用知识）

- **中文路径 × shell 桥接**：bash UTF-8 → cmd GBK 转换失败导致 `cmd //c`/`start` 找不到文件——独立后台进程一律用 Python `subprocess.Popen` + `DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP | CREATE_BREAKAWAY_FROM_JOB`（不带 BREAKAWAY 会被会话清理级联杀死，实测过"服务莫名消失"事故）
- **bat 编码规范**：GBK + CRLF、不用 `chcp 65001`、REM 只用 ASCII、统一 `set PYTHONIOENCODING=gbk`（防全局 PYTHONUTF8=1 下 Python 输出乱码）——全部 bat 由 `tools/gen_bats.py` 脚本生成，杜绝手编引入编码问题
- 以上经验全部沉淀在 `AGENTS.md`，任何 Agent 接手即继承

## 8. Agent 原生工作空间（本项目可直接作为任意 Agent 的工作目录）

- **`AGENTS.md`**（通用标准，Cursor/Codex/Gemini CLI 原生读取）+ **`CLAUDE.md`**（`@AGENTS.md` 指针，Claude Code 自动内联）——一份指令多 Agent 兼容
- 开篇即"运行环境探测协议"：教 Agent 先探测 `runtime\` / `.venv\` 再执行命令
- 完整 git 历史携带全部事故教训（"为什么这么写"可追溯）
- **83 个单元测试**作为环境健康自检：`runtime\python.exe -m pytest tests/ -v` 全绿即环境完好
- 未配置 LLM 时所有命令优雅降级：服务/检索/审计/测试可用，LLM 类命令输出一行配置指引退出（不裸堆栈、不挂死）

## 架构一览

```text
crawler/  采集层   sources.yaml → fetcher(限频) → browser(JS渲染) → parsers(PDF/doc/docx) → sync
app/      服务层   FastAPI → search(FTS5+向量RRF) → chat(Agent多轮+引用溯源) → relations(图谱) → wiki(缓存) → audit
web/      前端     原生单页（导航树/搜索/详情/图谱Canvas/对话悬浮窗），ES2017 兼容
data/     数据     knowledge.db（单文件 SQLite：laws/articles/relations/wiki_pages/标记表）
runtime/  便携运行时（分发形态） 内嵌 Python 3.14.5 + 全依赖
```
