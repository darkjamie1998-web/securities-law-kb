# 完全离线可跳转前端快照设计

日期：2026-11-04
状态：设计已获用户确认，待书面规格复核

## 1. 目标与交付物

将根目录 `证券法律法规知识库-前端快照.html` 改造成可完全离线打开的路演工作台。单个 HTML 内联页面结构、样式、原前端脚本、离线数据适配器、精选法规数据和预置问答，不要求启动 FastAPI、数据库或模型服务。

核心目标不是只保留静态外观，而是保留所有主要模块之间真实可操作的跳转关系。

## 2. 已确认边界

- 采用完全离线模式，不做在线检测或双模式。
- 复用完整 `web/index.html` DOM、`style.css`、`app.js` 和 `graph.js`，不基于当前单场景静态快照零散补链接。
- 在原前端脚本启动前安装 `window.fetch` 离线适配器，由统一数据集响应原 API 请求。
- 首页可展示本机全库统计快照；交互列表、搜索、阅读和图谱使用精选法规数据，并明确标注“精选离线演示数据”。
- 不宣称单文件包含全部 853 部法规，不把本地简单检索描述为后端混合检索。
- AI 对话使用预置问答；未预置问题明确提示离线限制，不伪造实时模型生成。
- 设置弹层只展示脱敏演示信息，不显示真实 API 地址、Key 或模型配置；保存与测试连接不得返回虚假成功。
- 官方原文属于外部链接，离线时说明需要联网；库内正文与证据跳转始终可用。

## 3. 路由与导航覆盖

必须支持直接打开和互相跳转：

| 路由 | 必备行为 |
|---|---|
| `#/home` | 首页、全库统计快照、可信状态、最近更新与最近浏览 |
| `#/laws` | 法规目录、级别/状态筛选、分页、卡片进入详情 |
| `#/search` | 全部/法规/法条范围、关键词搜索、筛选、独立分页 |
| `#/law/{id}` | 阅读器、正文分页、条号目录、篇内搜索、关联、预生成 Wiki |
| `#/graph` | 全景图谱、板块切换、图形交互、节点进入法规 |

同时保留：

- 品牌回首页、顶部搜索、侧栏级别与状态入口。
- 浏览器前进、后退、hash 深链接和未知路径回首页。
- 非法法规 ID、无搜索结果和空数据的正式状态。
- 对话浮层、证据抽屉、解读/关联侧栏、设置弹窗及移动端目录。

## 4. 离线数据与行为

### 4.1 统一精选数据集

使用同一组真实法规 ID、条文 ID、条号和正文片段生成全部 fixture，避免各模块各写一套数据。精选数据覆盖：

- 减持相关规章或修改决定。
- 《上市公司信息披露管理办法》。
- 信息披露暂缓与豁免相关规则。
- 至少一部交易所规则，用于体现自律规则层级。
- 至少一对双向法规关联和一组图谱边。
- 精选不少于 8 部法规；离线构建可将法规目录演示页大小设为 6，确保目录能够实际翻页。至少一部法规包含 50 条以上真实条文，用于验证阅读器正文分页。

法规、条文、搜索、阅读器、关系、图谱、聊天引用共用 ID。`law_id`、`article_id` 和 `article_no` 必须与原前端严格匹配。

### 4.2 离线 API 适配器

覆盖原前端可达端点：

- `GET /api/stats`
- `GET /api/laws`
- `GET /api/laws/{id}?mode=reader`
- `GET /api/laws/{id}/articles`
- `GET /api/laws/{id}/relations`
- `GET /api/search`
- `GET /api/graph`
- `POST /api/chat/stream` 与兼容回退 `POST /api/chat`
- `POST /api/laws/{id}/wiki`
- `GET /api/settings`、`PUT /api/settings`、`POST /api/settings/test`

列表和搜索支持精选数据范围内的关键词、级别、状态、来源、主题、排序与分页。阅读器支持正文分页、`article_no` 定位和篇内搜索。无结果返回真实空结果，不返回硬编码成功内容。

### 4.3 对话、证据与 Wiki

- 内置减持和信息披露两组问答，可演示阶段事件、回答、搜索词和引用列表。
- 引用可打开证据抽屉，并跳回对应法规和条号。
- 未预置问题返回明确离线提示，保留重试和清空等本地交互。
- Wiki 只展示预生成内容；重新生成返回离线不可用说明，不显示虚假进度。

### 4.4 本地能力

最近浏览、面板缩放与位置、图谱缩放/平移、复制条文等浏览器本地能力尽量沿用原实现。存储或剪贴板不可用时沿用原降级，不影响模块跳转。

## 5. 展示标识与安全

- 顶部保留简洁的“完全离线演示”标识，说明精选数据和预置问答边界。
- 页面不得自动发起任何 HTTP/HTTPS 资源或 API 请求，不得包含 CDN、外部字体或隐藏配置。官方原文只在用户主动点击时提示需要联网；完全断网时不打开外部页面，库内模块跳转不受影响。
- 不保留真实 API Key、接口地址或用户敏感信息。
- 页面根元素保留 `data-workmate-generated="true"`，末尾保留可见 `由 WORKMATE 生成`。
- 保持 ES2017 及以下 JavaScript 语法，避免新增 `?.`、`??` 等高版本语法。

## 6. 错误处理

- 无效 ID、未知路由、空搜索、无关联和无 Wiki 均显示明确状态。
- 未覆盖的 API 请求返回可读错误并在验证阶段视为缺陷，不能静默伪造成功。
- 外部原文、设置保存、连接测试和自由 AI 提问分别提供准确的离线说明。
- 离线适配器故障不得导致整个工作台空白；至少保留路由错误提示和返回首页能力。

## 7. 验收清单

1. 断网直接打开文件，所有主要路由均可访问，无外部资源请求。
2. 逐一点击品牌、侧栏、级别、状态、首页卡片、列表卡片、搜索结果、关联法规和图谱节点，目标模块正确。
3. 验证搜索范围、筛选、分页、阅读器翻页、条号定位和篇内搜索。
4. 验证两组预置问答、引用列表、证据抽屉及回到条文。
5. 验证浏览器前进后退、直接打开 hash、无效 ID 和空结果。
6. 检查控制台无未处理错误，所有 fixture 请求均被离线适配器覆盖。
7. 检查 1440×900、375×812 布局，移动端目录和弹层可操作，无页面级横向溢出。
8. 检查 WORKMATE 标识、离线边界、数据口径和无敏感配置。

## 8. 非目标

- 不在单文件中内嵌完整 SQLite 数据库。
- 不复现后端 BM25、trigram、向量 RRF 的真实排序效果。
- 不实现真实 LLM 对话、Wiki 生成、模型连接测试或每日同步。
- 不修改 FastAPI 业务源码，也不在本次任务中修复已发现的并发 SQLite 线程问题。
